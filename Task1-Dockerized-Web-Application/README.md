# CodSoft DevOps Internship - Task 1

## Dockerized Web Application

This task demonstrates how to build and run a web application inside a Docker container using Nginx.

### Objectives

- Create a simple web application
- Write a Dockerfile
- Build a Docker image
- Run the application inside a Docker container
- Verify the application through a web browser

### Technologies Used

- Docker
- Nginx
- HTML

### Docker Image

Image name:

codsoft-task1

### Docker Container

Container name:

codsoft-task1-container

### Port Mapping

Host port 8080 → Container port 80

The application can be accessed at:

http://localhost:8080

### Project Structure

Task1-Dockerized-Web-Application/
│
├── Dockerfile
├── index.html
└── README.md

### Result

The web application was successfully built as a Docker image and deployed inside an Nginx-based Docker container. The application was verified successfully through a web browser.
